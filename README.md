# דף נחיתה: Claude Code מאפס

דף סטטי אחד (`index.html`) עם הנכסים בתיקייה `assets/`. בלי build ובלי תלויות.

## 1. חיבור הטופס לגוגל שיטס (פעם אחת)
1. פותחות גיליון חדש ב-Google Sheets (למשל "הרשמות Claude Code מאפס").
2. בתפריט: **הרחבות ← Apps Script**.
3. מוחקות את מה שכתוב שם, מדביקות את כל התוכן של `apps-script.gs`, ושומרות.
4. **פריסה ← פריסה חדשה**. סוג: **אפליקציית אינטרנט**.
   - הפעלה בתור: **אני**
   - מי יכול לגשת: **כל אחד**
5. מאשרות את ההרשאות ומעתיקות את כתובת ה-Web App (מסתיימת ב-`/exec`).
6. ב-`index.html` מדביקות אותה בשורה:
   ```js
   const SHEET_URL = 'https://script.google.com/macros/s/.../exec';
   ```

כל הרשמה נכנסת כשורה בלשונית "הרשמות" (היא נוצרת לבד בהרשמה הראשונה).
אם משנות את הסקריפט אחר כך, צריך **פריסה ← ניהול פריסות ← עריכה ← גרסה חדשה**, אחרת השינוי לא נכנס.
